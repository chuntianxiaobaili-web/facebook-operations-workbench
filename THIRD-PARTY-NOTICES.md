# Third-party notices

The local browser application ships a production bundle based on React 19.3.1, React DOM 19.3.1, Scheduler 0.28.0 and StyleX 0.19.2. StyleX styles compile to static classes, with dynamic variants resolved using its runtime and styleq 0.2.1. Build-only tools and their versions are listed in `frontend/package-lock.json`.

The work queues and record states use the official Astryx Badge component from `@astryxdesign/core` 0.7.17. The bundled styles apply the official Neutral theme from `@astryxdesign/theme-neutral` 0.7.17.
